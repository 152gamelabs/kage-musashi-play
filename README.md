# 카게 무사시 모바일 테스트

공개 테스트: https://152gamelabs.github.io/kage-musashi-play/

가로 화면에서 조작 체험 또는 본편을 선택합니다. 게임 메뉴에서 버전을 확인하세요.
개발 중인 테스트판이며 휴대폰 앱 출시본과 구분합니다.

이 저장소에는 공개 웹 실행 빌드와 배포 설정만 보관합니다. 개발 원본은 별도 비공개 저장소에서 관리합니다.
게임 및 이미지·음악의 권리는 각 권리자에게 있으며 별도 허락 없이 재배포할 수 없습니다.

GitHub Releases의 `site.zip`을 GitHub Actions가 Pages에 배포합니다. 과거 버전은 Release로 보존하며 같은 주소를 갱신합니다.
AppDeploy 주소의 브라우저 저장은 이 주소로 자동 이전되지 않습니다. 새 주소의 저장은 이후 업데이트에서도 같은 브라우저에서 유지됩니다.
